<h4 id="bkmrk-overview">Overview</h4>
<p id="bkmrk-the-mel-label-printe">The MeL Label printer is used to generate routing slips for MeLCat interloan items. It uses an AHK script to fill in an 80mm receipt paper template that can be affixed to items using sticky receipt paper.</p>
<h4 id="bkmrk-components">Components</h4>
<ul id="bkmrk-mel-label-print.ahk-">
<li class="null">MEL-Locations.csv - a list of MeL libraries and their RIDES codes extracted from the <a href="https://members.mcls.org/w/melcatforms/melcontacts-rides.cfm" target="_blank" rel="noopener">RIDES Contact list</a></li>
<li class="null">MeL Sticky Label.dotx - routing slip template.</li>
<li class="null">MEL-Label-Print.ahk - AutoHotKey script.</li>
</ul>
<h4 id="bkmrk-to-use">To Use</h4>
<ul id="bkmrk-download-the-precomp">
<li class="null">Download the precompiled executable and template from the latest release. Save both files to the same directory.</li>
<li class="null">Edit lending library information and logo in MeL Sticky Label.dotx as needed.</li>
<li class="null">Run MEL-Label-Print.exe.<br></li>
<li class="null">Labels will print to your PC's default printer.</li>
<li class="null">The compiled release is configured to support Word version 2603</li>
</ul>
<h5 id="bkmrk-to-customize">To Customize</h5>
<p id="bkmrk-you-will-need-to-ins">You will need to install AutoHotKey, which can be found at <a href="https://www.autohotkey.com/">https://www.autohotkey.com/</a></p>
<ul id="bkmrk-edit-mel-label-print">
<li class="null">Edit MEL-Label-Print.ahk in your favorite text editor.</li>
<li class="null">Compile with ahk2exe. The script is written in <a href="https://www.autohotkey.com/docs/v1/" target="_blank" rel="noopener">AHK v1.1</a></li>
</ul>
